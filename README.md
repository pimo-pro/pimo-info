# pimo-info

Official documentation site for the PIMO industrial ecosystem (`pimo.pro`, `pimo-criativo`, `pimo-alfa`).

Built with Next.js and Nextra (docs theme).

## Scripts

```bash
npm install
npm run dev    # local development
npm run build  # production build
npm run start  # serve production build (Hostinger Node.js)
```

Requires Node.js 18+.
