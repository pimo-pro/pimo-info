# Definições

A rota `/definicoes` e as áreas de administração (`/admin/global-settings`, roles, permissões, room settings, industrial) concentram preferências e configuração do sistema.

## Níveis

| Nível | Onde | Conteúdo típico |
|---|---|---|
| Utilizador | `/definicoes`, `/me` | Preferências pessoais |
| Projeto | contexto do projeto | Unidades, materiais default |
| Global | `/admin/global-settings` | Defaults da instalação |
| Sala | `/admin/room-settings` | Ambiente / sala 3D |
| Industrial | `/admin/settings/industrial` | Alertas e parâmetros TRAK |

## Estado

**Disponível** (parcial na documentação de cada ecrã admin). A gestão avançada de roles/permissões está coberta de forma overview; detalhes de cada flag seguem o código da app.
