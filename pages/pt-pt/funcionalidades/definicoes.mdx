# Definições

A rota `/definicoes` e as áreas de administração concentram preferências e configuração do sistema. Rotas admin exigem permissões (`PermissionRoute` / `hasFullAccess` / `canAccessAdminPanel`) e login.

## Níveis

| Nível | Onde | Conteúdo típico |
|---|---|---|
| Utilizador | `/definicoes`, `/me` | Preferências pessoais |
| Projeto | contexto do projeto | Unidades, materiais default |
| Global | `/admin/global-settings` | Defaults da instalação |
| Sala | `/admin/room-settings` | Ambiente / sala 3D |
| Industrial | `/admin/settings/industrial` | Alertas e parâmetros TRAK |

## Administração (rotas verificadas)

| Área | Rota | Página |
|---|---|---|
| Utilizadores | `/admin/users` | `UsersAdminPage` |
| Partilhas de projeto | `/admin/project-shares` | `ProjectSharesAdminPage` |
| Roles | `/admin/roles` | `ManageRolesPage` |
| Permissões | `/admin/permissions` | `ManagePermissionsPage` |
| Global settings | `/admin/global-settings` | `GlobalSettingsAdminPage` |
| Room settings | `/admin/room-settings` | `RoomSettingsAdminPage` |
| Settings industriais | `/admin/settings/industrial` | `IndustrialAdminSettingsPage` |
| Alertas realtime | `/admin/system-settings/industrial/realtime-alerts` | `RealtimeAlertsAdminPage` |

## Estado

**Documentado a partir do código (outubro 2026):** rotas e páginas admin existem na app; o acesso depende de RBAC. Detalhe de cada flag continua na UI da app.
