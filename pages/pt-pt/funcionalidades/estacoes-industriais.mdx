# Estações industriais

As **estações** do fluxo industrial (verificadas em `App.tsx`) operam ordens de fabrico por posto:

| Estação | Rota (app) |
|---|---|
| Armazém | `/industrial/work-orders/warehouse` |
| Nesting | `/industrial/work-orders/nesting` |
| Furação | `/industrial/work-orders/drill` |
| Orlar | `/industrial/work-orders/orlar` |
| Montagem | `/industrial/work-orders/montagem` |
| Embalagem | `/industrial/work-orders/embalagem` |
| Supervisor | `/industrial/supervisor` |
| Operador | `/industrial/operador` |

Há ainda vistas de qualidade, retrabalho, time-tracking e tracking de peças sob `/industrial/*`.

## Estado

**Parcial**, ecrãs existem na app; a documentação de cada posto resume o papel no TRAK. App: [pimo.pro/industrial](https://pimo.pro/industrial).
