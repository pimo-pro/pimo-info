# Estações industriais

As **estações** do fluxo industrial (verificadas em `App.tsx` do PIMO PRO) operam ordens de fabrico por posto. Estas rotas vivem sob autenticação na app (`ProtectedLayout`).

## Estações de work order

| Estação | Rota (app) |
|---|---|
| Armazém | `/industrial/work-orders/warehouse` |
| Nesting | `/industrial/work-orders/nesting` |
| Furação | `/industrial/work-orders/drill` |
| Orlar | `/industrial/work-orders/orlar` |
| Montagem | `/industrial/work-orders/montagem` |
| Embalagem | `/industrial/work-orders/embalagem` |
| Por estação + projeto | `/industrial/work-orders/:station/:project` |
| Ordem / projeto | `/industrial/work-orders/order/:orderOrProject` |

## Perfis e supervisão

| Vista | Rota (app) |
|---|---|
| Supervisor | `/industrial/supervisor` |
| Supervisor por projeto | `/industrial/supervisor/:project` |
| Operador | `/industrial/operador` |
| Peça industrial | `/industrial/piece/:pieceId` |
| Execução de estação | `/industrial/stations/:station` |

## Vistas auxiliares (shell + QR)

Estas páginas montam `IndustrialLayout`, painel de leitura QR (`QrScannerPanel`) e um painel placeholder com nota de fase 3C.2 no código:

| Vista | Rota | Nota no código |
|---|---|---|
| Tracking | `/industrial/tracking` | Ligar snapshots de tracking e realtime |
| Qualidade | `/industrial/quality` | Ligar inspeções e rework automático |
| Retrabalho | `/industrial/rework` | Ligar fila de retrabalho |
| Time tracking | `/industrial/time-tracking` | Ligar timers operacionais |
| Eventos | `/industrial/events` | Ligar filtros e feed Supabase |

## Estado

**Documentado a partir do código (outubro 2026):** estações e perfis existem; as vistas auxiliares acima são shells com QR e placeholder. App: [pimo.pro/industrial](https://pimo.pro/industrial) (requer login).
