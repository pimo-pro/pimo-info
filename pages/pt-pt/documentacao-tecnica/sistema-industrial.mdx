# Sistema Industrial, visão consolidada

Camada industrial da app em `/industrial/*` (é preciso ter sessão iniciada), com hub de estações, work orders e operações.

## Rotas principais

| Área | Rota |
|---|---|
| Hub | `/industrial` |
| Work orders | `/industrial/work-orders` |
| Operações | `/industrial/operations` (+ `/cnc`, `/nesting`, `/drill`, `/orlar`, `/montagem`, `/embalagem`) |
| Tracking / quality / rework / time / events | `/industrial/tracking`, `/quality`, `/rework`, `/time-tracking`, `/events` |
| PIMO DRILL | `/industrial/pimo-drill` |
| Release notes industriais | `/industrial/release-notes` |

## Princípio de implementação

- Leitura de estado já existente no UI.
- Impacto operacional focado em visualização e clareza de processo nas fases visuais 1-6.

## Fases visuais (1-6)

1. Estrutura de página principal industrial.
2. Shell, rails e sinalética.
3. Tipografia e densidade de informação.
4. Motion e transições.
5. Contraste e legibilidade.
6. Destaques de tracking visual.

## Fases industriais (1-12)

1. QR / execução / dados.
2. Work Orders Engine.
3. Productivity Engine.
4. Cost Engine.
5. Real Execution Engine.
6. Real Data Engine.
7. Full Factory Engine.
8. Real Integration Engine.
9. Full Industrial Runtime.
10. Real Operations Engine.
11. Industrial Performance Engine.
12. Final Industrial Consolidation.

## Garantias explicitadas

- Sem alteração arbitrária de rotas `/industrial` existentes na documentação de fases.
- Shells de Tracking/Quality/Rework/Time/Events usam placeholder até ligarem dados reais.
- Preparado para integração futura com dados reais adicionais sem reescrever os painéis.

## Nota

Scores, tempos e custos exibidos nesta camada devem ser interpretados como leitura operacional/estimativa visual quando indicado, não como faturação oficial.
