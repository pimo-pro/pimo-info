# Guardar, carregar e gerir projetos

O sistema usa armazenamento local no navegador e permite exportação/importação JSON.

## Passo a passo

1. **Guardar**  
   Auto-save ativo e opção de guardar manualmente na barra superior.

2. **Abrir Meus Projetos**  
   Lista projetos com metadados e miniaturas.

3. **Carregar projeto**  
   Selecione o projeto e abra no workspace.

4. **Duplicar ou renomear**  
   Disponível por menu de contexto.

5. **Exportar/Importar JSON**  
   Recomendado para backup externo e partilha.

## Atenção

Se limpar os dados do browser, os projetos guardados localmente podem ser removidos.
