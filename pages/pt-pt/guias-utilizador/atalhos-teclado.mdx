# Atalhos de teclado do viewport

## Navegação e edição

- `S` — selecionar módulo.
- `M` — mover módulo.
- `R` — rodar módulo.
- `D` — mostrar/ocultar cotas.
- `G` — mostrar/ocultar grelha.
- `Home` — repor câmara.
- `Escape` — cancelar seleção.
- `Ctrl + Z` — desfazer.
- `Ctrl + Y` — refazer.
- `Botão direito` — menu de contexto do módulo.

## Dica

Para operações por módulo, o menu de contexto é a via mais rápida para duplicar, alinhar, renomear, trocar material ou remover.
